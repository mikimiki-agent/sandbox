# sandbox
dsh-superagent sandbox

## Überblick

Dieses Repository ist eine Sandbox für den dsh-superagent-Prototyp.
Es enthält keinen produktiven Code, sondern dient dazu, den Agenten
und seine Arbeitsweise auszuprobieren und zu demonstrieren. Aufträge
werden über Kommentare in den Issues erteilt, die `@mikimiki-agent`
erwähnen.
